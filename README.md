# Connor Fogg

Software engineer in American Fork, UT. I just finished the coursework for an M.S. in Computer Science at Utah Valley University.

Most of what I build is full-stack and AI-flavored: React/TypeScript on the front, PostgreSQL/Supabase behind it, and LLM features that get actually evaluated instead of just demoed. Before grad school I ran operations for a 10+ person business, which mostly means I care whether the people using a tool can actually use it.

## Projects

**[Fogg Properties](https://github.com/csfogg/fogg-properties)** — my M.S. capstone, and it's live: [fogg-properties.netlify.app](https://fogg-properties.netlify.app). Families photograph estate items, Gemini estimates a value for each from the photo, everyone marks what they want, and a snake draft divides things fairly. React, TypeScript, Supabase, Netlify serverless functions.

**[Elden Ring Region Classifier](https://github.com/csfogg/elden-ring-region-classifier)** — a ResNet18 that tells which region an Elden Ring screenshot came from. 99.5% test accuracy over 1,048 screenshots. PyTorch.

**[OS Virtual Machine](https://github.com/csfogg/os-virtual-machine)** — a semester-long operating systems project in Java: assembler, shell, FCFS/RR/MFQ scheduling, interrupts, paged memory. Partner project with [Stephen Hales](https://github.com/zhales05); we designed it jointly and split the code.

**[Rivals Randomizer](https://github.com/csfogg/rivals-randomizer)** — Marvel Rivals team comp randomizer for game nights. React, TypeScript, Vite.

**[Poor Man's DAGitty](https://github.com/csfogg/poor-mans-dagitty)** — a single-file causal DAG tool for quick backdoor/adjustment-set checks. Vanilla JS.
